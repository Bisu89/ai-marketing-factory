# AI Content Library — Documentation

Desktop-local content library for short-form video: paste a URL, detect the
platform, download, and manage the result in a searchable library (categories,
tags, favorites, status). FastAPI backend + React/TypeScript frontend +
SQLite.

40. [Batch Video Creation + Script Queue](features/40-batch-video-creation.md) — paste/upload N `---`-separated scripts → one template → N `Project` rows created transactionally; separate "Generate Beats" (bounded-concurrency AI) and "Render All" actions, both reusing the existing single-worker render queue with no second pipeline; the first real multi-`Project` DB table this app has had, alongside (not replacing) the singleton `beats.json` flow
41. [Local Asset Ingestion + Smart Library Preparation](features/41-local-asset-ingestion.md) — bulk-import a whole folder of local images/video into the existing `Asset` library: SHA-256 content dedup, EXIF-aware metadata, generated thumbnails, filename/folder-derived tags + category/emotion inference against the real existing catalogs, background job with progress/cancel, and a Re-scan for missing/restored files — all $0, no external API, no second asset system
42. 43. [Production Dashboard: Factory Control Center](features/43-production-dashboard.md) — repurposes the unbuilt `/dashboard` landing page into a real control center (KPI counts, current batch/render, needs-attention list, render queue, recent videos/failures, pipeline breakdown, $0 external-cost summary) via a single read-only `GET /dashboard` aggregation over Batch/Project/VideoComposeJob and the live Quality Gate; polling-based refresh (no push mechanism exists in this app)
44. [One-Click Factory Pipeline: Script → Beat → Visual → Quality → Render](features/44-one-click-factory-pipeline.md) — a new `FactoryRun` orchestration layer (its own pure module + a `factory_pipeline.py` composition root) that connects existing Beat generation, asset auto-assignment (reusing `AssetService.search()` + Task 16's confidence scoring), the unmodified Quality Gate, and the existing render queue into one "Create & Produce" action; idempotent, resumable, crash-recoverable, with a factory-level review policy layered on top of (never inside) the Quality Gate
45. [Factory Reliability: Persistent Checkpoints + Crash-Safe Resume](features/45-factory-reliability.md) — a new `FactoryCheckpoint` per-stage audit table, retry-attempt tracking + stable TRANSIENT/PERMANENT/USER_ACTION_REQUIRED error classification, and a real fix for a stale-COMPLETED-run reuse gap (an edited-then-re-produced project now starts a fresh run instead of silently returning the old result), on top of Task 18's already-durable `FactoryRun`
46. [Factory Batch Engine: Parallel Production with Safe Concurrency Limits](features/46-factory-batch-engine.md) — bounds Task 18's batch orchestration to `max_parallel_projects` (default 2) via a plain `ThreadPoolExecutor`, keeps `BatchItem.status` synced with each item's own `FactoryRun` for the first time, adds Pause/Resume/Cancel/Retry-Failed with atomic per-item claiming, and a process-wide AI-call semaphore shared with the older script-based batch flow — the existing single-worker render queue stays untouched and still the sole render concurrency limit
47. [Content Engine: Idea → Content Brief → Script](features/47-content-brief-script-engine.md) — a new `PREPARING_CONTENT` FactoryRun stage turns a one-line Idea into a structured `ContentBrief` then a `Script` (flattened to the same `script_text` Beat generation already consumes), reusing the existing Claude client/Template config/checkpoint/retry/batch-engine machinery end to end; found and fixed a real bug where several `BeatPlan` re-save sites (both backend and frontend) were silently dropping the new idea/content_brief/script_locked fields on every save
48. [Voice Factory: Local TTS → Beat Timing → Narration Track](features/48-voice-factory-local-tts.md) — a new `GENERATING_VOICE` FactoryRun stage synthesizes a real narration track via genuinely offline SAPI5 TTS (`edge_tts` kept as an explicit opt-in) and computes real per-beat timing (word-count/punctuation-weighted, normalized to measured audio duration, gapless), assigning each Beat's existing `narration_asset_id` field with zero render-pipeline changes; found and fixed a real SAPI5 deadlock under concurrent Factory Batch Engine threads by routing all TTS calls through one dedicated worker thread
49. [Local Motion Engine: Beat Visual → Animated Clip → FFmpeg](features/49-local-motion-engine.md) — a new `GENERATING_MOTION` FactoryRun stage turns each Beat's visual Asset into a real, cached, independently-retryable animated clip (deterministic FFmpeg Ken-Burns for images with configurable intensity/focal point/auto-rotation, trim/scale/crop for existing video assets, reused outright by the final render when still valid); found and fixed a real pre-existing bug where every pan/zoom preset froze mid-clip at any output fps other than 25, caught only by real pixel-level manual verification
50. [Audio Master: Narration + Local BGM → Ducking → Final Audio](features/50-audio-master.md) — a new `GENERATING_AUDIO` FactoryRun stage mixes narration with optional local BGM (deterministic tone-tag selection + seeded rotation, manual override, loop/trim, real ffmpeg `sidechaincompress` ducking verified by signal level, `loudnorm` normalization) into one cached, validated `audio_master.wav`, reusing the exact ducking recipe `VideoComposerService._mix_audio` already has in production; BGM tracks are ordinary local Assets, no new music database
51. [Caption Engine: Script/Timing → Styled Captions → ASS](features/51-caption-engine.md) — a new `GENERATING_CAPTIONS` FactoryRun stage turns each Beat's own final narration text plus its Voice-settled timing into a styled, cached `captions.ass` (deterministic phrase-boundary segmentation with weighted, min/max-duration-bounded timing; all 5 existing caption presets, duplicating `video_composer.service`'s own proven ASS template rather than importing it), with no ASR/AI transcription/caption API involved — purely local and $0
52. [Final Composer: Beat Clips + Audio Master + Captions → final.mp4](features/52-final-composer.md) — extends the existing `VideoComposerService`/`VideoComposeJob` renderer (no second queue) with a new single-pass "precomposed" mode: Beat clips concatenated via ffmpeg's own `concat` filter, Audio Master mapped straight through as the sole audio track, Captions burned in via `subtitles=`, an optional watermark via `overlay=`, all in one ffmpeg call producing `final.mp4`; a real Audio Master is now a hard requirement for every Factory render, and final-output validation was tightened to require exactly one video and one audio stream
53. [Thumbnail + Metadata: Final Video → Ready-to-Post Package](features/53-thumbnail-metadata-package.md) — a new `PACKAGING` FactoryRun stage turns `final.mp4` into `thumbnail.jpg` (deterministic candidate-frame extraction + brightness/contrast/edge-density scoring, no AI vision, graceful fallback instead of hard-failing when every candidate is flat/low-detail) + `metadata.json` (deterministic title/description/hashtag templates from Task 21's own ContentBrief, manual overrides always win, no LLM call); `retry_run`/`retry_batch_failed` both gained an explicit Packaging-only resume path so a crash there never silently re-renders the whole video

54. [Final QA + Ready-to-Post: Validate the Finished Package](features/54-final-qa.md) — a new `FINAL_QA` FactoryRun stage re-verifies the finished package (video streams/resolution/fps/duration, audio silence/clipping, thumbnail/metadata/caption validity, dependency staleness) via real ffprobe/volumedetect/Pillow probes; a FAIL routes to `NEEDS_REVIEW` with a per-issue `repair_stage`, mirroring the pre-render Quality Gate's own review treatment

55. [Dual AI Provider: Claude + OpenAI, Selectable in Settings](features/55-dual-ai-provider.md) — a new `app.modules.ai.llm_client` abstraction (mirrors the Voice module's own `TTSProvider`/`get_provider` pattern) lets every AI text-generation call use either Anthropic Claude or OpenAI, switchable anytime via a new Settings provider toggle; also fixes a real prompt issue where OpenAI models wrote scripts 2-3x the intended length until the target word count was stated explicitly

56. [Classic Render: Burned Captions for Local-Voice Quick Render / Batch Render](features/56-classic-render-captions.md) — the classic Quick Render/Batch Render paths never called Task 25's Caption Engine, so local-voice narration (this app's own default) never got burned captions regardless of the "Enable captions" checkbox; also moves the image + motion-preset picker onto the Beats step itself so a beat's visual is editable without navigating to a separate step

57. [Asset Library: Delete Action](features/57-asset-library-delete.md) — a "Delete" button in the asset detail panel wires up the backend's already-existing `DELETE /assets/{id}` endpoint for the first time; only unregisters the asset (the real file on disk is untouched)

58. [Auto-Sync Beat Duration to Narration Length + Folder Browse Fixes](features/58-beat-duration-narration-sync.md) — attaching narration audio to a beat now bumps its duration up to fit, instead of only failing at render time; fixes a real `os.listdrives()` (Python 3.12+-only) crash in the folder-browse endpoint on this app's Python 3.11, and adds a "Browse..." folder picker to Asset Library's Import Folder tab
